# Яндекс Метрика и Вебмастер

Основной сайт: https://prime-com.ru/. Счётчик Метрики: **112484093**, владелец — аккаунт компании `info@prime-com.ru`. Часовой пояс — Москва, валюта — рубли, фильтрация роботов — по строгим правилам и поведению. Статистика не является публичной.

Код добавляется сервером после применения правок из CMS. Он работает на `prime-com.ru` и `www.prime-com.ru` по HTTPS. Админка, предпросмотр, localhost и GitHub Pages не отправляют посещения. Код и файл подтверждения не экспортируются в демонстрацию.

Включены карта кликов, отслеживание ссылок, точный показатель отказов и Вебвизор. Запись содержимого полей отключена в настройках счётчика; полям дополнительно присваивается `ym-disable-keys`. Автоматический сбор контактных данных выключен. События передают только имя цели, без текста заявки или данных посетителя.

| Событие | Цель |
| --- | --- |
| `phone_click` | Клик по телефону |
| `email_click` | Клик по электронной почте |
| `telegram_click` | Переход в Telegram |
| `vk_click` | Переход во ВКонтакте |
| `price_open` | Открытие прайс-листа |
| `contact_sent` | Заявка успешно сохранена сервером |

Цель заявки вызывается только в успешном ответе после записи сообщения, а не при нажатии кнопки. Автоматические цели отключены, чтобы не дублировать эти события.

`/sitemap.xml` формируется из опубликованных страниц. Черновики, редиректы, страницы с `noindex` и страницы с другим canonical не включаются. Адрес карты указан в `robots.txt`. При изменении SEO через админку карта обновляется автоматически.

Подтверждение Вебмастера: `/yandex_781ffa2c4df60895.html`. Это публичный код подтверждения владения, а не OAuth-токен. OAuth-токен нужен только для настройки сервисов, не хранится в исходниках и не требуется приложению при работе.
