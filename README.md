# ПраймКом — копия сайта

[Репозиторий](https://github.com/Kibosh13/primecom-copy) · [Статическая демонстрация](https://kibosh13.github.io/primecom-copy/)

Рабочая копия публичной части сайта на отдельном движке Node.js: 73 HTML-страницы, 77 адресов с учётом перенаправлений и 426 файлов оформления и материалов (216.5 МиБ).

## Запуск

Нужен Node.js 22 или новее. В папке проекта выполните:

```sh
npm start
```

Откройте [http://127.0.0.1:4173/](http://127.0.0.1:4173/). Устанавливать дополнительные пакеты не требуется. Проверено на Node.js 25.6.1.

Адрес и порт задаются переменными `HOST` и `PORT`. По умолчанию сервер доступен только на этом компьютере. На новом сервере эту папку можно использовать целиком; подключение домена, HTTPS и почты выполняется при размещении.

## Содержимое

- `pages/` — страницы с оригинальной разметкой и текстами. Названия файлов соответствуют разделам сайта; страницы с параметрами находятся в `_queries/`.
- `public/` — локальные изображения, PDF, документы, шрифты, CSS и JavaScript.
- `routes.json` — адреса страниц, названия, источники и перенаправления.
- `server.mjs` — обработка адресов, выдача файлов и приём заявок.
- `recovery-manifest.json`, `RESTORE-NOTES.md` — происхождение материалов и особенности восстановления.
- `scripts/` — проверка материалов, статический экспорт и публикация демоверсии. Локальные отчёты проверок исключены из Git.

После изменения HTML или файлов достаточно обновить страницу. После изменения `server.mjs` сервер нужно перезапустить.

## Что важно знать

Это копия публичных страниц, а не резервная копия VPS или базы Joomla. Исходный PHP-код, база и административная панель Joomla в комплект не входят. Сайт работает без них.

13 страниц получены с действующего сайта 7 сентября 2026 года. Ещё 59 страниц восстановлены из публичных архивов; большая часть этих снимков относится к июлю и августу 2026 года, отдельные страницы старше. Даты каждой страницы указаны в `RESTORE-NOTES.md`. Поэтому идентичность всех текстов сегодняшней версии оригинала не гарантируется.

Страница «Презентации возможностей» восстановлена как указатель на семь существующих статей: её оригинал не удалось получить. Четыре старых адреса перенаправляются на соответствующие сохранившиеся страницы.

Форма обратной связи сохраняет заявки в `data/inquiries.jsonl`. Почтовая доставка пока не подключена; после отправки форма прямо сообщает об этом. Признак запроса копии письма также сохраняется. Данные заявок не выдаются через веб-сервер и не включены в архив проекта.

Чат-бот AgentX и счётчик Метрики требуют отдельного подключения перед публикацией. Карты и внешние ссылки на видео, приложения и социальные сети используют интернет. Остальные ресурсы страниц находятся локально.

## Проверка

```sh
npm run build
```

Проверка подтверждает наличие локальных ресурсов и внутренних переходов. Синтаксис JavaScript, восстановленные пакеты PageSpeed и обработчик заявок также проверены. Полное сравнение скриншотов с исходным сайтом не выполнялось.

## GitHub и демонстрация

Репозиторий публичный. Ветка `main` содержит исходный движок, страницы и материалы. Ветка `gh-pages` содержит только готовую статическую демонстрацию; GitHub Pages публикует её из корня ветки. Node.js на GitHub Pages не запускается.

В демонстрации отключены отправка и сохранение заявок, почтовая доставка, чат-бот и аналитика. Старая административная панель Joomla отсутствует и в исходном проекте. Каталог, навигация, галереи и документы доступны. Внешние карты и ссылки требуют интернета.

Все HTML-файлы демоверсии, включая перенаправления и страницу 404, содержат `noindex, nofollow, noarchive`. Также включён `robots.txt` с запретом обхода. Для проекта внутри подпапки поисковики читают robots.txt в корне домена: на момент публикации `https://kibosh13.github.io/robots.txt` уже содержит `Disallow: /`. Запрет индексации не является ограничением доступа: демонстрация и репозиторий публичны.

Подготовка и проверка статической версии:

```sh
npm run build:demo
```

Результат находится в `dist/` и исключён из `main`. Старые адреса Joomla с параметрами заменяются отдельными HTML-файлами. Локальные ссылки и стили получают префикс `/primecom-copy/`.

Обновление после правок:

```sh
git add pages public scripts server.mjs package.json README.md routes.json
git commit -m "Обновить материалы сайта"
git push origin main
npm run deploy:demo
```

Публикация выполняется из чистой ветки `main` с настроенной авторизацией GitHub. Скрипт сохраняет историю `gh-pages`, отправляет только изменившиеся файлы и не создаёт коммит при отсутствии изменений. Принудительная перезапись ветки не используется. Если другой участник изменил ветку во время публикации, Git отклонит отправку; сначала нужно согласовать изменения. Не редактируйте сгенерированную ветку вручную.

ZIP-архивы, `.env*`, приватные данные заявок, базы данных, зависимости, кэши, логи и результаты локальных проверок исключены через `.gitignore`. Вход на GitHub использует системную авторизацию `gh`; токены не записываются в проект.
