# Панель управления ПраймКом

Панель `/admin/` работает на основном сервере Node.js и не входит в статическую демонстрацию GitHub Pages.

## Первый вход

На сервере один раз выполните `npm run admin:setup` с тем же `CMS_DATA_DIR`, который использует приложение. Команда выдаст персональную ссылку на 48 часов. Откройте её по HTTPS и задайте логин и собственный пароль длиной от 12 символов. После создания администратора ссылка перестаёт действовать. Повторный запуск команды не заменяет существующего администратора. В хранилище сохраняется только хеш ссылки; пароли хешируются scrypt. Не публикуйте ссылку в Git или открытой переписке.

## Разделы

- **Страницы:** поиск по названию, адресу и разделу. Внутри редактора отдельные вкладки для текстов, изображений, ссылок, SEO и истории. Шапка, меню, содержимое и подвал выбираются отдельно. Оформление сохраняется; введённый текст не превращается в исполняемый HTML.
- **Черновик:** сохраняет изменения без публикации. «Предпросмотр» сначала сохраняет правки и открывает черновик; отправка форм в нём отключена. «Опубликовать» делает изменения видимыми посетителям.
- **История:** 20 предыдущих публикаций каждой страницы. Восстановление создаёт черновик; его нужно отдельно опубликовать.
- **Медиатека:** существующие изображения и загрузка JPG, PNG, GIF, WebP до 8 МБ. Редактор меняет изображение на одной странице и его alt. Медиатека позволяет заменить все использования файла, включая фоны и скрипты. Исходный файл сохраняется, замену можно отменить. Лимит загрузок — 2 ГБ.
- **SEO:** title, description, keywords, canonical, индексация, Open Graph и приблизительный вид поисковой карточки.
- **Контакты:** компания, почта, телефоны, офис, склад и карты. Сохранение сразу применяет их к стандартным контактам сайта. Особые контакты внутри статей редактируются на соответствующих страницах.
- **Заявки:** последние 200 сообщений из форм сайта, телефон клиента и статус отправки. Письма отправляются на почту из раздела «Контакты»; при ошибке заявка остаётся в панели.
- **Настройки:** смена пароля с подтверждением текущего; остальные сеансы после смены завершаются.

## Данные и обновления

По умолчанию данные находятся в `data/cms/`, на Beget — в отдельном `~/prime-com.ru/content/`. Здесь хранятся учётная запись, сеансы, черновики, публикации, история, контакты и изображения. Каталог исключён из Git и не является публичным. Сервер выдаёт через `/uploads/` только изображения с проверкой имени и MIME-типа. SVG и исполняемые файлы загружать нельзя.

При обновлении кода сохраняйте `content/` и `inquiries/`. Для полной резервной копии нужны исходники и обе приватные папки; храните её вне публичного каталога и GitHub. Опубликованная через панель страница имеет приоритет над HTML в `pages/`, поэтому обновление кода не затирает работу редактора. Если исходный шаблон такой страницы изменился, объединение нового шаблона и контента выполняется отдельно.

Правки из панели не отправляются автоматически в GitHub. GitHub Pages остаётся отдельной статической демонстрацией исходных страниц без работающей админки и личных данных.

Сохранения проверяют номер версии и защищают от перезаписи чужих изменений. Файлы записываются атомарно. После аварийного завершения процесса может остаться `.write-lock`; удалять его вручную можно только убедившись, что запись уже не выполняется.

Маршруты панели и API закрыты от индексации. Сеанс действует 8 часов; cookie — HttpOnly и SameSite=Strict, в production также Secure. Изменения требуют Origin и CSRF-токен. Предпросмотр изолирован в iframe. На основном сайте SSL и редирект HTTP → HTTPS должны работать до первого входа администратора.
