# Статическая демонстрация ПраймКом

Исходники и инструкции: https://github.com/Kibosh13/primecom-copy/tree/main

73 страниц и 4 перенаправления. Формы не отправляют и не сохраняют данные. Сервер Node.js, почтовая доставка, административная панель, чат-бот и аналитика здесь не запускаются. Внешние карты и ссылки требуют интернета.

Все HTML-страницы содержат noindex, nofollow, noarchive. robots.txt запрещает обход. Это указания поисковикам, а не ограничение доступа к публичной демонстрации.

Обновляйте через npm run deploy:demo из main. Не редактируйте эту ветку вручную.
