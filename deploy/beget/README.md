# Размещение на Beget

Используется имеющийся виртуальный хостинг, Ubuntu 22.04, Node.js 24.15.0 и Apache Passenger. Установка соответствует [инструкции Beget](https://beget.com/ru/kb/how-to/web-apps/node-js).

Сайт размещён для `prime-com.ru` и `www.prime-com.ru`. В NIC.ru 10 сентября 2026 года сохранены DNS-серверы `ns1.beget.com`, `ns2.beget.com`, `ns1.beget.pro`, `ns2.beget.pro`. В зоне Beget обе A-записи указывают на `45.130.41.82` — адрес, который панель Beget потребовала для выпуска SSL. HTTP-запросы к этому адресу с обоими именами домена проверены.

SSL управляется через «Домены → prime-com.ru → Управление SSL сертификатами». После установки бесплатного Let's Encrypt нужно проверить HTTPS для обоих имён и включить «Редирект с HTTP на HTTPS» в настройках сайта. Редирект включается только после проверки сертификата. Движок допускает публичные проверочные файлы `/.well-known/acme-challenge/`; остальные скрытые каталоги закрыты.

Структура внутри каталога сайта `prime-com.ru`:

- `app/` — Git-репозиторий, ветка `main`;
- `runtime/` — Node.js из официального дистрибутива, проверенного по SHA-256;
- `public_html` — ссылка на `app/public`, сюда помещается `.htaccess` по примеру;
- `inquiries/` — приватные заявки, вне публичного каталога и репозитория;
- `content/` — приватное хранилище панели управления, публикаций и изображений;
- `public_html.before-deploy/` — сохранённая исходная заглушка Beget.

Passenger запускает `deploy/beget/start.cjs`, который загружает основной `server.mjs`. Статические файлы выдаёт хостинг, страницы, панель и старые адреса Joomla обрабатывает Node.js. Нужны пакеты из `package-lock.json`; отдельная база данных не требуется.

После входа по SSH перейдите в Docker командой `ssh localhost -p 222`. Для обновления используйте:

```sh
cd ~/prime-com.ru/app
git status --short
git pull --ff-only origin main
../runtime/bin/node ../runtime/lib/node_modules/npm/bin/npm-cli.js ci --omit=dev
../runtime/bin/node scripts/validate.mjs
cp deploy/beget/htaccess.example public/.htaccess
mkdir -p tmp
touch tmp/restart.txt
```

Если есть локальные изменения, сначала выясните их происхождение. Не применяйте принудительную перезапись. Каталоги `inquiries` и `content` сохраняются между обновлениями. Пароли хостинга и NIC.ru не хранятся в проекте.

Первоначальная настройка новой панели после активации HTTPS:

```sh
cd ~/prime-com.ru/app
CMS_DATA_DIR=../content ../runtime/bin/node scripts/admin-bootstrap.mjs
```

Команда выводит одноразовую ссылку на 48 часов. Передайте её владельцу сайта приватно; он сам задаёт логин и пароль. Если администратор уже настроен, команда не заменит его доступ. [Руководство по панели](../../admin/README.md).

Форма сохраняет заявки на сервере. Автоматическая пересылка на электронную почту пока не подключена; подтверждение отправки предлагает телефон и почту для оперативной связи. Исходная Joomla и её административная панель не входят в восстановленный проект.

На основном домене индексация разрешена. Экспорт GitHub Pages по-прежнему добавляет `noindex` и собственный `robots.txt` с запретом обхода. При переносе DNS почта остаётся на Яндексе: следует сохранить существующие MX, SPF, DKIM и CNAME `mail`.
