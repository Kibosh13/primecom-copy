# Размещение на Beget

Используется имеющийся виртуальный хостинг, Ubuntu 22.04, Node.js 24.15.0 и Apache Passenger. Установка соответствует [инструкции Beget](https://beget.com/ru/kb/how-to/web-apps/node-js).

Структура внутри каталога сайта `prime-com.ru`:

- `app/` — Git-репозиторий, ветка `main`;
- `runtime/` — Node.js из официального дистрибутива, проверенного по SHA-256;
- `public_html` — ссылка на `app/public`, сюда помещается `.htaccess` по примеру;
- `inquiries/` — приватные заявки, вне публичного каталога и репозитория;
- `public_html.before-deploy/` — сохранённая исходная заглушка Beget.

Passenger запускает `deploy/beget/start.cjs`, который загружает основной `server.mjs`. Статические файлы выдаёт хостинг, страницы и старые адреса Joomla обрабатывает Node.js. Дополнительные пакеты и база данных не требуются.

После входа по SSH перейдите в Docker командой `ssh localhost -p 222`. Для обновления используйте:

```sh
cd ~/prime-com.ru/app
git status --short
git pull --ff-only origin main
../runtime/bin/node scripts/validate.mjs
mkdir -p tmp
touch tmp/restart.txt
```

Если есть локальные изменения, сначала выясните их происхождение. Не применяйте принудительную перезапись. Каталог `inquiries` сохраняется между обновлениями. Пароли хостинга и NIC.ru не хранятся в проекте.

Форма сохраняет заявки на сервере. Автоматическая пересылка на электронную почту пока не подключена; подтверждение отправки предлагает телефон и почту для оперативной связи. Исходная Joomla и её административная панель не входят в восстановленный проект.

На основном домене индексация разрешена. Экспорт GitHub Pages по-прежнему добавляет `noindex` и собственный `robots.txt` с запретом обхода. При переносе DNS почта остаётся на Яндексе: следует сохранить существующие MX, SPF, DKIM и CNAME `mail`.
